# Bienvenido a Caddy

Caddy es una plataforma potente y extensible para servir tus sitios, servicios y aplicaciones, escrita en Go. Si eres nuevo en Caddy, la forma en que sirves la Web está a punto de cambiar.

## Introduction

La mayoría de personas usa Caddy como servidor web o proxy, pero en su núcleo, Caddy es un servidor de servidores. Con los [módulos requeridos](/docs/modules/), puede asumir el papel de cualquier proceso de larga duración.

La configuración es dinámica y exportable con [la API de Caddy](/docs/api). Aunque no se requieren archivos de configuración, todavía puedes usarlos; la forma favorita de muchos para configurar Caddy es usando [Caddyfile](/docs/caddyfile). El formato del documento de configuración puede tomar muchas formas con los [adaptadores de configuración](/docs/config-adapters), pero el lenguaje de configuración nativo de Caddy es [JSON](/docs/json/).

Caddy se compila para todas las plataformas principales y no tiene dependencias en tiempo de ejecución.


## ¿Primera vez?

¡No hay problema! **Sugerimos que _todos_, independientemente de su experiencia, revisen nuestra [guía de inicio](/docs/getting-started).** Te dará una visión completa de tu nuevo servidor web que te será invaluable al seguir aprendiendo.

Si solo tienes unos minutos y necesitas empezar de inmediato, prueba uno de nuestros [inicios rápidos](/docs/quick-starts).

Para contenido ampliado como ejemplos concretos, revisa [nuestra wiki comunitaria](https://caddy.community/c/wiki/13) y luego contribuye a ella.

Recomendamos usar estos recursos oficiales para [instalar](/docs/install), [configurar](/docs/caddyfile) y [ejecutar](/docs/command-line) Caddy, en lugar de copiar comandos o fragmentos de configuración de blogs aleatorios o foros de preguntas y respuestas. Encontrarás que nuestro material suele ser más preciso y actualizado. También te animamos a crear tus propias configuraciones para asegurarte de que entiendes cómo funciona tu servidor y puedas resolver problemas con mayor facilidad si aparecen más adelante.

Pero hagas lo que hagas, disfruta usar tu nuevo servidor web. ¡Caddy es una experiencia diferente a cualquier otro software de servidor que hayas usado!


## Obtener ayuda

Si necesitas ayuda usando Caddy, pregunta en [nuestro foro comunitario](https://caddy.community). Estaremos encantados de ayudarte. Solo pedimos que completes la plantilla de ayuda lo más completamente posible y que también ayudes a otros. Siempre necesitamos más colaboradores.

Usa únicamente [nuestro sistema de incidencias](https://github.com/caddyserver/caddy/issues) si has identificado claramente un error en Caddy o tienes una solicitud de función específica.

Este sitio web se [mantiene en GitHub](https://github.com/caddyserver/website). Para proponer mejoras, abre una incidencia o una pull request.

Gracias por participar en nuestra comunidad. Esperamos que Caddy te sirva muy bien.
