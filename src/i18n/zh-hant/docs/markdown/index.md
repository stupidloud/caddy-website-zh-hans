# 歡迎使用 Caddy

Caddy 是一個以 Go 語言編寫，功能強大且具擴充性的平台，可用於託管您的網站、服務和應用程式。如果您是第一次接觸 Caddy，您提供網路服務的方式即將迎來變革。

## 簡介

大多數人將 Caddy 作為網頁伺服器或代理伺服器使用，但就其核心而言，Caddy 是一個「伺服器的伺服器」。透過安裝[必要的模組](/docs/modules/)，它可以承擔任何長期執行程序的角色！

透過 [Caddy 的 API](/docs/api)，設定既是動態的，也是可匯出的。雖然不需要設定檔，但您仍可以使用它們；大多數人最喜歡的 Caddy 設定方式是使用 [Caddyfile](/docs/caddyfile)。透過[設定轉接器 (config adapters)](/docs/config-adapters)，設定文件的格式可以有多種形式，但 Caddy 原生的設定語言是 [JSON](/docs/json/)。

Caddy 可為所有主要平台編譯，且沒有執行階段依賴性。


## 第一次使用？

沒問題！**我們建議「每個人」無論經驗如何，都請先閱讀我們的[入門指南 (Getting Started guide)](/docs/getting-started)。** 這將為您的新網頁伺服器提供一個全面的視角，對您之後的學習將非常有幫助。

如果您只有幾分鐘時間並需要立即上手，請嘗試我們的其中一個[快速入門](/docs/quick-starts)。

如需更多內容（例如特定範例），請查看[我們的社群維基 (community wiki)](https://caddy.community/c/wiki/13) - 並歡迎為其做出貢獻！

我們建議使用這些官方資源來[安裝](/docs/install)、[設定](/docs/caddyfile)和[執行](/docs/command-line) Caddy，而不是從隨機的部落格或問答討論區複製指令或設定片段。您會發現我們的教材通常更準確且及時。我們也鼓勵您親手撰寫設定，以確保您了解伺服器的運作方式，這樣如果日後出現問題，您將能更有能力解決。

但無論您做什麼，請享受使用您的新網頁伺服器。Caddy 的體驗與您使用過的其他伺服器軟體截然不同！


## 尋求協助

如果您在服務 Caddy 時需要協助，請在[我們的社群論壇](https://caddy.community)中禮貌地提問。我們很樂意為您提供協助。我們唯一的請求是請您盡可能詳盡地填寫協助範本，並透過幫助他人來回饋社群。我們總是需要更多的志願者。

請僅在您確認發現 Caddy 的錯誤 (bug) 或有特定功能需求時，才使用[我們的問題追蹤器 (issue tracker)](https://github.com/caddyserver/caddy/issues)。

本網站[在 GitHub 上進行維護](https://github.com/caddyserver/website)。若要提交改進建議，請開啟 issue 或發起 pull request。

感謝您參與我們的社群！我們希望 Caddy 能為您提供良好的服務。
