# Benvenuti in Caddy

Caddy è una piattaforma potente ed estensibile per distribuire i vostri siti, servizi e app, scritta in Go. Se non avete mai usato Caddy, il vostro modo di gestire il Web sta per cambiare.

## Introduzione

La maggior parte delle persone utilizza Caddy come server web o proxy, ma nel suo nucleo, Caddy è un "server di server". Con i [moduli necessari](/docs/modules/), può assumere il ruolo di qualsiasi processo a lunga esecuzione!

La configurazione è sia dinamica che esportabile grazie all'[API di Caddy](/docs/api). Sebbene non siano richiesti file di configurazione, è comunque possibile utilizzarli; il modo preferito dalla maggior parte degli utenti per configurare Caddy è il [Caddyfile](/docs/caddyfile). Il formato del documento di configurazione può assumere molte forme grazie agli [adattatori di configurazione](/docs/config-adapters), ma il linguaggio di configurazione nativo di Caddy è il [JSON](/docs/json/).

Caddy viene compilato per tutte le principali piattaforme e non ha dipendenze a runtime.


## Prima volta?

Nessun problema! **Suggeriamo a _tutti_, indipendentemente dall'esperienza, di consultare la nostra [Guida introduttiva](/docs/getting-started).** Vi fornirà una prospettiva completa sul vostro nuovo server web che si rivelerà preziosa man mano che continuerete a imparare.

Se avete solo pochi minuti e avete bisogno di iniziare subito, provate uno dei nostri [avvii rapidi](/docs/quick-starts).

Per contenuti approfonditi come esempi specifici, consultate il [nostro wiki della comunità](https://caddy.community/c/wiki/13) e date il vostro contributo!

Raccomandiamo di attenervi a queste risorse ufficiali per [installare](/docs/install), [configurare](/docs/caddyfile) ed [eseguire](/docs/command-line) Caddy, piuttosto che eseguire comandi o copiare frammenti di configurazione da blog casuali e bacheche di Q&A. Scoprirete che il nostro materiale è generalmente più accurato e aggiornato. Vi incoraggiamo inoltre a creare le vostre configurazioni per assicurarvi di capire come funziona il vostro server, in modo da essere più capaci di risolvere eventuali problemi se si dovessero presentare in futuro.

Ma qualunque cosa facciate, godetevi l'uso del vostro nuovo server web. Caddy è un'esperienza diversa da qualsiasi altro software server abbiate mai usato!


## Richiedere aiuto
