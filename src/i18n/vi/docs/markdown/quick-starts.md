# Bắt đầu nhanh

Các hướng dẫn này được thiết kế để giúp bạn bắt đầu và chạy nhanh chóng mà không có nhiều lời giải thích cản trở.

Bạn **rất nên** đọc các hướng dẫn khác và tài liệu tham khảo để hiểu đầy đủ về cách máy chủ web của mình hoạt động.
