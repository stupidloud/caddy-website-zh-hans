# Caddy へようこそ

Caddy は、サイト、サービス、アプリを配信するための強力で拡張可能なプラットフォームです。Go で書かれています。Caddy が初めてなら、Web の配信方法に対する見方が変わるはずです。

<a id="introduction"></a>
## 概要

多くの人は Caddy を Web サーバーやプロキシとして使いますが、中核にあるのは「サーバーのためのサーバー」です。[必要なモジュール](/docs/modules/)があれば、長時間動作するあらゆるプロセスの役割を担えます。

設定は [Caddy の API](/docs/api) によって動的に変更でき、エクスポートもできます。設定ファイルは必須ではありませんが、もちろん使えます。多くの人が好む Caddy の設定方法は [Caddyfile](/docs/caddyfile) です。設定ドキュメントの形式は [config adapters](/docs/config-adapters) によってさまざまな形を取れますが、Caddy のネイティブな設定言語は [JSON](/docs/json/) です。

Caddy は主要なプラットフォームすべて向けにコンパイルでき、実行時の依存関係はありません。


<a id="first-time"></a>
## 初めてですか？

問題ありません。**経験に関係なく *すべての人* に [はじめにガイド](/docs/getting-started) を読むことをおすすめします。** 新しい Web サーバーを学び続けるうえで役立つ、全体像のよい見通しが得られます。

数分しかなく、すぐに動かす必要がある場合は、[クイックスタート](/docs/quick-starts) のいずれかを試してください。

具体的な例など、より広い内容については [コミュニティ wiki](https://caddy.community/c/wiki/13) を確認してください。そして、ぜひ貢献してください。

Caddy を [インストール](/docs/install)、[設定](/docs/caddyfile)、[実行](/docs/command-line) するには、ランダムなブログや Q&A サイトのコマンドや設定スニペットをコピーするのではなく、これらの公式リソースを使うことをおすすめします。一般に、公式資料のほうが正確で最新です。また、自分のサーバーがどのように動くかを理解できるよう、自分で設定を書くことも推奨します。そうしておけば、後で問題が起きたときに修正しやすくなります。

いずれにしても、新しい Web サーバーを楽しんで使ってください。Caddy は、これまで使ってきたどのサーバーソフトウェアとも違う体験です。


<a id="getting-help"></a>
## ヘルプを得る

Caddy の使い方で助けが必要な場合は、[コミュニティフォーラム](https://caddy.community) で丁寧に質問してください。喜んでお手伝いします。お願いしたいのは、ヘルプ用テンプレートをできるだけ詳しく埋めること、そして可能なら他の人も助けてコミュニティに還元することです。私たちは常に協力してくれる人を必要としています。

[issue tracker](https://github.com/caddyserver/caddy/issues) は、Caddy のバグを明確に特定した場合、または具体的な機能リクエストがある場合にのみ使ってください。

この Web サイトは [GitHub でメンテナンスされています](https://github.com/caddyserver/website)。改善を提案するには、issue または pull request を開いてください。

コミュニティへの参加ありがとうございます。Caddy があなたの役に立つことを願っています。
