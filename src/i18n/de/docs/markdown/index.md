# Willkommen bei Caddy

Caddy ist eine leistungsfähige, erweiterbare Plattform zum Bereitstellen deiner Websites, Dienste und Apps, geschrieben in Go. Wenn Caddy neu für dich ist, wird sich die Art ändern, wie du das Web bereitstellst.

<a id="introduction"></a>
## Einführung

Die meisten Menschen verwenden Caddy als Webserver oder Proxy, aber im Kern ist Caddy ein Server für Server. Mit den [erforderlichen Modulen](/docs/modules/) kann er die Rolle jedes langlebigen Prozesses übernehmen.

Konfiguration ist sowohl dynamisch als auch über [Caddys API](/docs/api) exportierbar. Obwohl keine Konfigurationsdateien erforderlich sind, kannst du sie weiterhin verwenden; die bevorzugte Art der Caddy-Konfiguration ist für viele das [Caddyfile](/docs/caddyfile). Das Format des Konfigurationsdokuments kann mit [config adapters](/docs/config-adapters) viele Formen annehmen, aber Caddys native Konfigurationssprache ist [JSON](/docs/json/).

Caddy lässt sich für alle wichtigen Plattformen kompilieren und hat keine Laufzeitabhängigkeiten.


<a id="first-time"></a>
## Zum ersten Mal hier?

Kein Problem! **Wir empfehlen *allen*, unabhängig von der Erfahrung, unseren [Getting Started guide](/docs/getting-started) durchzuarbeiten.** Er gibt dir einen runden Überblick über deinen neuen Webserver, der beim weiteren Lernen sehr wertvoll sein wird.

Wenn du nur wenige Minuten Zeit hast und sofort loslegen musst, probiere einen unserer [quick starts](/docs/quick-starts) aus.

Für erweiterte Inhalte wie konkrete Beispiele schau in unser [Community-Wiki](https://caddy.community/c/wiki/13) und trage gern selbst dazu bei.

Wir empfehlen, dich an diese offiziellen Ressourcen zum [Installieren](/docs/install), [Konfigurieren](/docs/caddyfile) und [Ausführen](/docs/command-line) von Caddy zu halten, statt Befehle aus beliebigen Blogs oder Q&A-Seiten auszuführen oder Konfigurationsschnipsel von dort zu kopieren. Unsere Inhalte sind in der Regel genauer und aktueller. Außerdem ermutigen wir dich, deine eigenen Konfigurationen zu erstellen, damit du verstehst, wie dein Server funktioniert, und spätere Probleme besser beheben kannst.

Was auch immer du tust: Viel Freude mit deinem neuen Webserver. Caddy ist anders als jede andere Serversoftware, die du bisher verwendet hast.


<a id="getting-help"></a>
## Hilfe bekommen

Wenn du Hilfe bei der Verwendung von Caddy brauchst, frage bitte freundlich in [unserem Community-Forum](https://caddy.community). Wir helfen dir gern. Wir bitten nur darum, dass du die Hilfevorlage so vollständig wie möglich ausfüllst und später auch anderen hilfst. Wir brauchen immer mehr Helfer.

Nutze [unseren Issue Tracker](https://github.com/caddyserver/caddy/issues) nur, wenn du eindeutig einen Bug in Caddy identifiziert hast oder eine konkrete Feature-Anfrage hast.

Diese Website wird [auf GitHub gepflegt](https://github.com/caddyserver/website). Um Verbesserungen einzureichen, öffne ein Issue oder einen Pull Request.

Danke, dass du Teil unserer Community bist. Wir hoffen, Caddy wird dir gute Dienste leisten.
