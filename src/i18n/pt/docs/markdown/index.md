# Bem-vindo ao Caddy

Caddy é uma plataforma poderosa e extensível para servir sites, serviços e aplicativos, escrita em Go. Se você está começando com o Caddy, a forma de publicar na Web está prestes a mudar.

<a id="introduction"></a>
## Introdução

A maioria das pessoas usa o Caddy como servidor web ou proxy, mas, no fundo, o Caddy é um servidor de servidores. Com os [módulos necessários](/docs/modules/), ele pode assumir o papel de qualquer processo de longa duração.

A configuração pode ser alterada dinamicamente e exportada pela [API do Caddy](/docs/api). Embora arquivos de configuração não sejam obrigatórios, você ainda pode usá-los. A forma favorita de muita gente para configurar o Caddy é usando o [Caddyfile](/docs/caddyfile). O formato do documento de configuração pode assumir muitas formas com os [adaptadores de configuração](/docs/config-adapters), mas a linguagem nativa de configuração do Caddy é [JSON](/docs/json/).

O Caddy é compilado para todas as principais plataformas e não tem dependências em tempo de execução.

<a id="first-time"></a>
## Primeira vez?

Sem problema! **Sugerimos que *todos*, independentemente da experiência, leiam nosso [guia de primeiros passos](/docs/getting-started).** Ele oferece uma visão geral bem equilibrada do seu novo servidor web, algo valioso enquanto você continua aprendendo.

Se você só tem alguns minutos e precisa começar rápido, experimente um dos nossos [inícios rápidos](/docs/quick-starts).

Para conteúdo mais amplo, com exemplos específicos, confira [a wiki da comunidade](https://caddy.community/c/wiki/13) - e depois contribua com ela!

Recomendamos usar apenas estes recursos oficiais para [instalar](/docs/install), [configurar](/docs/caddyfile) e [executar](/docs/command-line) o Caddy, em vez de copiar comandos ou trechos de configuração de blogs aleatórios e fóruns de perguntas e respostas. Você verá que nosso material é, em geral, mais preciso e mais atualizado. Também incentivamos você a criar suas próprias configurações para garantir que entende como o servidor funciona, o que vai ajudá-lo a corrigir problemas caso eles apareçam mais tarde.

Mas, independentemente do que fizer, aproveite o seu novo servidor web. O Caddy é uma experiência diferente de qualquer outro software de servidor que você já tenha usado!

<a id="getting-help"></a>
## Obter ajuda

Se você precisar de ajuda para usar o Caddy, pergunte com educação no [nosso fórum da comunidade](https://caddy.community). Teremos prazer em ajudar. Só pedimos que você preencha o modelo de ajuda o mais detalhadamente possível e que retribua ajudando outras pessoas. Sempre precisamos de mais colaboradores.

Use o [rastreador de issues](https://github.com/caddyserver/caddy/issues) apenas se você tiver identificado claramente um bug no Caddy ou tiver uma solicitação de recurso específica.

Este site é [mantido no GitHub](https://github.com/caddyserver/website). Para enviar melhorias, abra uma issue ou pull request.

Obrigado por participar da nossa comunidade! Esperamos que o Caddy lhe sirva bem.
