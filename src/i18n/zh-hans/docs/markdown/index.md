# 欢迎使用 Caddy

Caddy 是一个功能强大且可扩展的 Web 服务器平台，专为托管您的网站、服务和应用程序而设计，采用 Go 语言编写。如果您是 Caddy 的新用户，您的 Web 托管方式即将焕然一新。

## 引言

大多数人将 Caddy 用作 Web 服务器或代理，但从本质上讲，Caddy 是一个“服务器中的服务器”。只要安装了[相应的模块](/docs/modules/)，它就能承担任何长期运行进程的角色！

借助 [Caddy 的 API](/docs/api)，配置既可以是动态的，也可以导出。虽然不需要配置文件，但您仍然可以使用它们；大多数人最喜欢的配置 Caddy 的方式是使用 [Caddyfile](/docs/caddyfile)。借助[配置适配器](/docs/config-adapters)，配置文档的格式可以多种多样，但 Caddy 的原生配置语言是 [JSON](/docs/json/)。

Caddy 可在所有主流平台上编译，且不依赖任何运行时组件。


## 第一次来吗？

没问题！**我们建议*所有人*，无论经验如何，都阅读我们的《[入门指南](/docs/getting-started)》。** 它将帮助您全面了解新的 Web 服务器，这对您今后的学习将大有裨益。

如果您只有几分钟时间，且需要立即上手，不妨尝试我们的[快速入门指南](/docs/quick-starts)。

如需查看具体示例等扩展内容，请访问[我们的社区维基](https://caddy.community/c/wiki/13)——欢迎踊跃参与编辑！

我们建议您在[安装](/docs/install)、[配置](/docs/caddyfile)和[运行](/docs/command-line) Caddy 时，请务必遵循这些官方资源，而不是直接执行命令或从随机的博客和问答论坛中复制配置片段。您会发现，我们的资料通常更加准确且及时。我们也鼓励您亲自编写配置文件，以确保您理解服务器的运行原理，这样一旦日后出现问题，您将更有能力进行排查和解决。

无论您做什么，都请尽情享受这款新Web服务器的乐趣吧。Caddy带来的体验，与您以往使用过的任何服务器软件都截然不同！


## 寻求帮助

如果您在使用 Caddy 时需要帮助，请在[我们的社区论坛](https://caddy.community)中礼貌地提出请求。我们很乐意为您提供帮助。我们仅需您尽可能详细地填写求助模板，并通过帮助他人来传递这份善意。我们始终需要更多的志愿者。

请仅在您已确切发现 Caddy 中的错误或有具体的功能请求时，才使用[我们的问题跟踪器](https://github.com/caddyserver/caddy/issues)。

本网站[托管于 GitHub](https://github.com/caddyserver/website)。如需提交改进建议，请创建问题或提交拉取请求。

感谢您加入我们的社区！希望 Caddy 能为您提供优质的服务。
