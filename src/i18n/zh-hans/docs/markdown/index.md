# 欢迎使用 Caddy

Caddy 是一个强大、可扩展的平台，用于托管你的网站、服务和应用，它使用 Go 编写。如果你刚开始接触 Caddy，那么你提供 Web 服务的方式即将发生改变。

<a id="introduction"></a>
## 介绍

大多数人把 Caddy 用作 Web 服务器或代理，但从本质上说，Caddy 是“服务器的服务器”。借助[所需模块](/docs/modules/)，它可以承担任何长期运行进程的角色。

配置既可以动态修改，也可以通过 [Caddy 的 API](/docs/api) 导出。虽然并不要求使用配置文件，但你仍然可以使用它们；大多数人最喜欢的 Caddy 配置方式是使用 [Caddyfile](/docs/caddyfile)。配置文档的格式可以通过 [config adapters](/docs/config-adapters) 呈现为多种形式，但 Caddy 的原生配置语言是 [JSON](/docs/json/)。

Caddy 可以编译到所有主流平台，并且没有运行时依赖。


<a id="first-time"></a>
## 第一次使用？

没问题！**无论你经验如何，我们都建议*每个人*先阅读[入门指南](/docs/getting-started)。** 它会帮你全面了解这台新的 Web 服务器，这对你后续继续学习非常有价值。

如果你只有几分钟，并且需要马上上手，可以尝试我们的任意一篇[快速入门](/docs/quick-starts)。

如果需要更丰富的内容，例如具体示例，请查看[社区 wiki](https://caddy.community/c/wiki/13)，也欢迎贡献内容。

我们建议你坚持使用这些官方资源来[安装](/docs/install)、[配置](/docs/caddyfile)和[运行](/docs/command-line) Caddy，而不是从随机博客或问答网站运行命令、复制配置片段。你会发现我们的资料通常更准确，也更新得更及时。我们也鼓励你自己编写配置，确保你理解服务器的工作方式；这样以后出现问题时，你会更有能力修复它们。

但无论如何，希望你享受使用这台新 Web 服务器的过程。Caddy 会带来不同于你用过的任何其他服务器软件的体验。


<a id="getting-help"></a>
## 获取帮助

如果你在使用 Caddy 时需要帮助，请在[社区论坛](https://caddy.community)中友善提问。我们很乐意帮助你。我们只希望你尽可能完整地填写求助模板，并通过帮助他人把这份善意传递下去。我们一直需要更多愿意帮忙的人。

只有在你确定发现了 Caddy 的 bug，或有具体功能请求时，才使用我们的 [issue tracker](https://github.com/caddyserver/caddy/issues)。

本网站[在 GitHub 上维护](https://github.com/caddyserver/website)。如需提交改进，请打开 issue 或 pull request。

感谢你参与我们的社区！希望 Caddy 能很好地为你服务。
