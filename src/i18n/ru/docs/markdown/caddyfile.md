# Caddyfile

**Caddyfile** — удобный для людей формат конфигурации Caddy. Для большинства пользователей это любимый способ использовать Caddy, потому что его легко писать, легко понимать, и он достаточно выразителен для большинства сценариев.

Он выглядит так:

```caddy
example.com {
	root /var/www/wordpress
	encode
	php_fastcgi unix//run/php/php-version-fpm.sock
	file_server
}
```

(Это настоящий production-ready Caddyfile, который обслуживает WordPress с полностью управляемым HTTPS.)

Базовая идея в том, что сначала вы указываете адрес сайта, а затем функции или поведение, которые нужны вашему сайту. [Посмотреть больше распространенных шаблонов.](/docs/caddyfile/patterns)

<a id="note"></a>
## Примечание

Caddyfile — это всего лишь [адаптер конфигурации](/docs/config-adapters) для Caddy. Его обычно предпочитают при ручном составлении конфигураций, но он не такой выразительный, гибкий и программируемый, как [собственная JSON-структура](/docs/json/) Caddy. Если вы автоматизируете конфигурации или развертывания Caddy, возможно, стоит использовать JSON вместе с [API Caddy](/docs/api). (На самом деле Caddyfile тоже можно использовать с API, но только в ограниченной степени.)
