# Bienvenue sur Caddy

Caddy est une plateforme puissante et extensible pour servir vos sites, services et applications, écrite en Go. Si vous découvrez Caddy, votre manière de servir le Web est sur le point de changer.

## Introduction

La plupart des gens utilisent Caddy comme serveur web ou proxy, mais au fond, Caddy est un "serveur de serveurs". Avec les [modules requis](/docs/modules/), il peut assumer le rôle de n'importe quel processus de longue durée !

La configuration est à la fois dynamique et exportable via l'[API de Caddy](/docs/api). Bien qu'aucun fichier de configuration ne soit requis, vous pouvez toujours en utiliser ; la méthode préférée de beaucoup pour configurer Caddy est d'utiliser le [Caddyfile](/docs/caddyfile). Le format du document de configuration peut prendre de nombreuses formes grâce aux [adaptateurs de configuration](/docs/config-adapters), mais le langage de configuration natif de Caddy est le [JSON](/docs/json/).

Caddy se compile pour toutes les plateformes majeures et n'a aucune dépendance d'exécution.


## Première fois ?

Pas de problème ! **Nous suggérons à *tout le monde*, quel que soit son niveau d'expérience, de lire notre [guide de premiers pas](/docs/getting-started).** Il vous donnera une perspective complète sur votre nouveau serveur web, ce qui sera inestimable pour la suite de votre apprentissage.

Si vous n'avez que quelques minutes et que vous devez être opérationnel rapidement, essayez l'un de nos [démarrages rapides](/docs/quick-starts).

Pour des contenus plus approfondis comme des exemples spécifiques, consultez [notre wiki communautaire](https://caddy.community/c/wiki/13) — puis contribuez-y !

Nous vous recommandons de vous en tenir à ces ressources officielles pour [installer](/docs/install), [configurer](/docs/caddyfile) et [exécuter](/docs/command-line) Caddy, plutôt que d'exécuter des commandes ou de copier des extraits de configuration provenant de blogs aléatoires ou de forums de questions-réponses. Vous constaterez que notre matériel est généralement plus précis et à jour. Nous vous encourageons également à concevoir vos propres configurations pour vous assurer de comprendre le fonctionnement de votre serveur, afin d'être plus apte à résoudre les problèmes s'ils surviennent ultérieurement.

Quoi que vous fassiez, profitez bien de votre nouveau serveur web. Caddy est une expérience unique, différente de tout autre logiciel serveur que vous avez pu utiliser !


## Obtenir de l'aide

Si vous avez besoin d'aide pour utiliser Caddy, veuillez demander poliment sur [notre forum communautaire](https://caddy.community). Nous serons ravis de vous aider. Tout ce que nous vous demandons, c'est de remplir le modèle d'aide aussi précisément que possible, et de renvoyer l'ascenseur en aidant les autres. Nous avons toujours besoin de plus de bras.

N'utilisez [notre outil de suivi de problèmes](https://github.com/caddyserver/caddy/issues) que si vous avez formellement identifié un bug dans Caddy ou si vous avez une demande de fonctionnalité spécifique.

Ce site web est [maintenu sur GitHub](https://github.com/caddyserver/website). Pour proposer des améliorations, ouvrez un ticket ou une pull request.

Merci de participer à notre communauté ! Nous espérons que Caddy vous sera très utile.
